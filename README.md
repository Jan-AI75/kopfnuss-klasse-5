# Maxis Kopfnuss

Lernspiel für die 5. Klasse (Realschule und Gymnasium, Bayern), läuft im Browser auf Tablet, Handy und PC.

- 10 gemischte Fragen pro Runde aus Deutsch, Mathe, Erdkunde, Geschichte, Biologie und Physik
- 10 Punkte pro richtige Antwort, ab drei richtigen in Folge +5 Bonus
- Ab 60 Punkten wird das vorher gewählte Belohnungsspiel freigeschaltet: Katapult, Ballons platzen, Obst-Schnitt, Torwandschießen oder Maulwurf hauen

Punkte und Fortschritt werden nur im jeweiligen Browser gespeichert (localStorage). Es werden keine Daten an einen Server geschickt.

Die ganze App steckt in einer einzigen Datei: `index.html`.
